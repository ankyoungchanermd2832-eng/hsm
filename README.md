# HSM — 우리집 수납정리 (Home Storage Management)

집 도면 사진을 등록하고 방마다 수납공간(책장, 서랍장, 장롱, 선반, 싱크대)을 배치한 뒤,
각 수납공간 안의 바구니에 보관한 물건을 등록해두면 검색으로 바로 찾을 수 있는 앱입니다.

> ER-STT(응급실 음성기록) 앱과는 완전히 별개의 독립된 저장소입니다.

## 주요 기능

- **도면 업로드**: 집 도면 사진을 올리고, 사진 위에 드래그로 방 영역을 표시합니다.
- **수납공간 배치**: 방을 열어 책장·서랍장·장롱·선반을 등각(isometric) 입체 아이콘으로 바닥에 배치하고, 드래그로 위치를 조정합니다.
- **싱크대 디자인 갤러리**: 주방에는 6가지 싱크대(주방 수납장) 디자인 예시 중 골라서 실제 배치처럼 놓을 수 있습니다.
- **바구니 & 물건 등록**: 수납공간을 클릭하면 안에 진열된 바구니 목록이 열리고, 바구니마다 아이콘과 이름으로 물건을 등록합니다. 물건은 이름 기준 가·나·다 / a·b·c 순으로 자동 정렬됩니다.
- **통합 검색**: 상단 검색창에 물건 이름을 입력하면 어느 방·수납공간·바구니에 있는지 즉시 찾아주고, 클릭하면 해당 위치로 이동합니다.

## 실행하기 (Windows)

이 폴더 안의 **`run.bat`을 더블클릭**하면 됩니다.
`git clone`으로 받은 폴더라면 실행할 때마다 자동으로 `git pull`을 돌려 최신 버전을 받아온 뒤 서버를 켜고 브라우저를 엽니다.
(zip으로 받아서 `.git` 폴더가 없는 경우에는 자동 업데이트 없이 그냥 지금 버전으로 실행돼요.)

- Node.js가 설치되어 있지 않다면 먼저 https://nodejs.org 에서 설치해주세요.
- 휴대폰에서도 쓰려면, 컴퓨터와 휴대폰을 같은 와이파이에 연결한 뒤 실행 중인 창에 뜨는 `Network:` 주소를 휴대폰 브라우저에 입력하세요.
- 창을 닫으면 서버가 꺼집니다. 다시 쓰려면 `run.bat`을 다시 더블클릭하세요 — 그때 또 자동으로 최신 버전을 받아옵니다.

## 개발 (터미널)

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입체크 + 프로덕션 빌드
```

데이터는 브라우저의 localStorage에 저장됩니다 (별도 백엔드 없음).
